**Findings** (written to REVERSE.md)
- **Slot copy is one byte short:** it copies `$2FF` bytes, not `$300`, so the last byte of each save slot is never copied.
- **Refused autosaves are only partly mirrored:** when saving isn't allowed, `SaveGame` copies the backup mirror only from offset = area id onwards. The cause is that `SaveAllowed` leaves the area id in X.
- **Each slot is written twice, but only the first copy is ever loaded.**
- **Saving and loading take real time on the NES.** A save spans 4 frames and a load spans 1 frame. The first fix (instant copies) left the port 4 frames ahead after a save. I measured the exact frame and scanline in the emulator and the port now waits the same number of frames.
