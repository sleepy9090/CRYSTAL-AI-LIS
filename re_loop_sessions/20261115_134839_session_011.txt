Banks 21–23 are English dialogue text: plain ASCII plus a 128-word dictionary. There is no DTE and no compression. The end of bank 23 isn't text at all; it's the save/load code.

**Text format**
- **Encoding:** bytes `$20-$7E` are plain characters. Bytes `$80-$FF` are dictionary words, looked up through the pointer table at `20:8900`. Bytes `$00-$09` are control codes: end, clear box, newline, wait for a button press, player name (from `$6400`), three name tables, current item, and N spaces.
- **Printer:** `TextPrint` at `20:853A`. The message is chosen by `$07DF` (group) and `$07DE` (message within the group). Each group's bank comes from `20:83FE`: groups 0–13 are in bank 21, 14–25 in bank 22, and 26–33 in bank 23. The pointer tables are at `20:8422`.
- **Text box:** the text is built in a buffer at `$6000-$60FF`. That buffer is uploaded to nametable 2 at PPU `$2820-$291F`, four double-spaced lines.
- **Spacing quirk:** after a dictionary word or a name-table string, the printer adds a space only if the next byte meets a specific rule. Plain characters never get one. The web port has to copy this rule exactly or spacing will come out wrong.
- **Decoded output:** I wrote `tools/text_dump.py` and ran it. It decoded all 511 messages in 34 groups with no unknown control codes, written to `gfx/text.txt` and `gfx/text.json`.

**Save/load code (bank 23 `$BC00`)**
- **Entry points:** `SaveGame`, `LoadGame` and `LoadGameAndInit`.
- **When saving is allowed:** a per-area table at `23:BF00` decides whether the current area can save.
- **What a save does:** it stores the area and player state at `$7DF0-$7DF8` and writes a 3-byte tag `AMI` at `$7DFD`. It then runs five block copies, writes an 8-bit checksum to `$70F5`, and copies everything to a backup at `$6D00`.
- **Copy-length quirk:** the block-copy routine copies `lo + 1 + hi` bytes instead of the intended 16-bit count. For example, a count of `$01FF` copies 257 bytes. The port needs the same lengths.
- **Correction:** the old notes said bank 23 is mapped at one place (`30:C9DF`). It is actually mapped at 7 places, including from bank 16 code and the boot check.
