**What I found**
- **Table size:** `MainStateTable` (`30:C91F`) is 9 words. Entries 6 and 7 are empty (`$0000`). Entry 8 is `30:C9DA`, the **continue-from-save** state. It sets up the objects, loads the save (`LoadGameAndInit`, bank 23), builds the screen, then switches to gameplay at substate 1.
- **Names:** 0 = new game, 1 = gameplay, 2 = title init, 3 = title, **4 = ending init (`17:A000`)**, **5 = ending (`17:A100`)**, 8 = continue.
- **Every write to `main_state` (`$40`):**
  - Reset sets 2.
  - Game over (`PlayerDeath` `19:B9AD`) sets 2, so it goes back to the title.
  - Name entry sets 0.
  - On the title menu, SELECT flips `$82` between the two choices. START with `$82`=1 sets 8 (continue); otherwise it starts a new game.
  - `19:BFC4`, the end of the final cut-scene (substate 30), sets 4. It is the only way into the ending.
  - The ending init steps to 5, and nothing ever leaves state 5. The game stays there until reset.
- **State 5 per frame:** it has three modes chosen by `$0602`: run the scene, fade in, or fade out. The scene mode works through a list of 20 or more steps.
