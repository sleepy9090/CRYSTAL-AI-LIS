**Findings (in REVERSE.md and labels.csv)**
- **Correction:** a shot's spawn offset comes from the *spawned* object's `obj_behav`, not the shooter's. As a negative test, the old reading fails 192 of the 1000 cases.
- **Fan-turret quirk:** its idle path jumps into `AiShootCheck` instead of calling it. So when an attack starts, `AiShootCheck` drops `ObjUpdateAll`'s own return address, `ObjUpdateAll` returns early, and every later slot misses its AI update that frame. All 37 cases that hit this path match.
- `DirToTarget` doesn't clamp distances: for objects more than a screen apart it uses the high byte as the distance, so direction and distance come out wrong. This only affects offscreen objects.
- `ObjInit` leaves bank 13 mapped (the far-call wrapper restores the banks), and type `$FF` only clears the slot.
- The two position-add helpers handle the y carry differently.
