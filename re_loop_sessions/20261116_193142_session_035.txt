**New `tools/emu/mapper.py`:**
- **Bank switching:** the 8 bank registers and both layouts for the code area, `$8000-$FFFF` (mode 0 or mode 1). Graphics banks can be laid out either way round (2KB+1KB or the swapped halves). Bank numbers wrap at 32 code banks and 128 graphics banks.
- **Screen mirroring** (`$A000`): horizontal or vertical. A helper turns a screen address into its offset in the console's 2KB of video RAM.
- **Save RAM gate** (`$A001`): turns the battery RAM on or off and can make it read-only. The memory bus now respects this; when the RAM is off, reads return whatever was last on the bus.
- **Scanline interrupt** (`$C000-$E001`): the line counter that lets the game change the picture partway down the screen. The graphics chip (emu 3/6) can drive it in two ways:
  - **Simple:** call `clock_scanline()` once per line.
  - **Exact:** report each low-to-high change on PPU address line A12 to `ppu_a12(level, dot)`. A change only counts after the line has been low for about 3 CPU cycles, which is how the real chip filters them.
- **Save-states:** `state()` and `load_state()` capture and restore the chip's settings, for emu 4/6.
- **Bus wiring:** creating the memory bus with a cartridge now builds the MMC3 automatically. The temporary stand-in mapper is kept only for CPU-only tests.
