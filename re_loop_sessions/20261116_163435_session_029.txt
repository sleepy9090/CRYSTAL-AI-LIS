**New tool: `tools/ram_map.py` → `docs/ram_map.txt`**
- It reads the full disassembly (`disasm/bank_NN.asm`) and counts every reference to RAM (`$0000-$07FF`) and WRAM (`$6000-$7FFF`). For each address it lists reads, writes, which index register is used, which banks touch it, and its label.
- It also finds parallel arrays: bases accessed with the same index register at a fixed spacing.
- It found **612 addresses** in use. 118 had labels before; **364 do now**. I added 246 labels, one for every address with 3 or more references.
- About half the new labels are placeholder names (`tmp_XX`, `zp_XX`, `ram_XXXX`, `wram_XXXX`). Each has a comment with its read/write counts and banks so a later session can rename it.

**What the map shows**
- **Object table:** the 4 position arrays at `$70-$EF` and 30 arrays from `$0300-$06BF`, plus `$06E0`. Each holds one byte per object for 32 objects (slot 0/1 = player).
- **Newly named object fields:** I named 14 of them from behaviour already written up in REVERSE.md, for example:
  - `obj_attack` `$03E0` and `obj_defense` `$0400`
  - `obj_timer` `$0480` and `obj_death_type` `$04C0`
  - `obj_elem_drop` `$0500`: low half is element bits, high half is the gold-drop class
  - `obj_phase` `$0600` and `obj_param1/2` `$0680/$06A0`
  - Slot-specific references get names like `obj_flags_s01`, and `$71`/`$B1` are the player's x/y.
- **Still unknown:** four object fields (`$03A0`, `$05A0`, `$0640`, `$0660`). They are left for the next object-struct task.
- **Sound driver:** it keeps 18 small arrays at `$0114-$017F`, 6 bytes apart (one entry per sound channel), used only in bank 24.
- **Save data:**
  - `$70F0-$70F3` are the two save slots' checksum bytes.
  - `$646B` bit 0 is the save slot picked in the menu.
  - `$7000` is set to one value while the menu Save command runs and another when it exits.
- **Title/menu reuse:** the title and menu code (banks 17-19) uses `$72-$8F` and `$0600-$06FF` while the object table is cleared. References only from that code got plain `zp_`/`ram_` names instead of object-slot names.
