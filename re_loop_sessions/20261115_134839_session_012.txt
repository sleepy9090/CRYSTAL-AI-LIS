**(a) How a message is chosen**
- Every message in gameplay goes through `ShowMessage` at `30:D354`. While a message is open, Select replays it and A/B closes it.
- There is a second entry point at `30:D347` that takes a single message number (group × 32 + message) and splits it into group and message.
- Enemy and event code in banks 15, 19, 26 and 27 queues a message in `$06C3`/`$06E3`, and `30:D085` shows it.
- **Talking to an NPC** runs a small script engine in bank 14 (`14:8000`):
  - It works on 2048 story flags at `$6480` and a per-NPC conversation state at `$6580`; both are saved with the game.
  - A script is a list of flag tests. The first test that passes picks the reply, may set or clear flags, and may move the NPC to its next conversation state.
  - Each reply also carries an action number. Bank 30 runs it from a 32-entry table at `30:D123`, for example "teach magic".
  - The decoded scripts for all 256 NPC ids, with message text, are in `gfx/npc_scripts.txt` and `.json`.
- Session 11 listed 8 places that set the message number. There are actually 27; I traced the main ones and listed the rest as a follow-up.

**(b) Bank 20 text and window**
- The text at `20:8466-8527` is never read. It's a leftover byte-for-byte copy of bank 22 at the same offset, probably from an earlier build.
- `20:8500` opens the text window: it draws a 10-row frame at the top of nametable 2 from 3-byte row templates. It sends the tiles to the screen through an 8-entry PPU upload queue at `$6200`.

**(c) Characters on screen**
- The text box loads CHR banks `$3C-$3D`, and each letter's tile number is simply its ASCII code, so there is no conversion table.
- Tiles `$18-$1F` are the window frame, `$40` is the ▼ prompt and `$FE` is blank. The second half of that pattern table (`$38-$39`) holds the status-bar tiles.
- I rendered and checked this in `gfx/font.png`.

**(d) The per-area tables**
- In `23:BF00`, bit 0 means "the Save command in the menu is allowed in this area" (`16:9BE1`). Bit 7 means the save code actually writes the record.
- Bank 21 has no separate table. Its `$BF00` holds the end of the real text up to `$BF30`, then another leftover copy of the bank 23 table. `31:FDE0-FDFD` is a similar unused copy of save code.
