I worked through the teleport-pick item from the Ph6 scenario leftovers task. Session 85 thought pressing DOWN then A in the teleport menu "did not pick"; the keys were fine and the test setup was the problem.

**Why nothing was picked**
- Picking a town with A (`30:DC70`) works out an index from the cursor (row × 3 + column) and only accepts it if that town's flag F2F5+index is set (checked by `TestFlagF2F0`). The 11 flags live in `$64DE` bits 5-7 and `$64DF` bits 0-7.
- If the flag is clear, the press is ignored and the menu keeps waiting. A new game has none of these flags set, so the old `use_warp` and `mp_teleport` scenarios could never leave the menu.
- These flags are the "silent one-shot triggers" already listed in the Flags table. They are the teleport menu's town unlocks, set when the player first reaches each town.
