**(b) How player shots damage enemies (`26:90AA`), plus the other hit handlers**
- **Level gate:** the low bits of an enemy's hit flags are the player level needed to hurt it. Below that level, the shot just bounces off with a "clink" sound. The old guess that this was the enemy's own level was wrong.
- **Damage:** player attack + shot attack − enemy defence. A shot that does damage keeps flying; a shot that misses is removed.
- **Elements:** an enemy's element bits list the sword elements it is immune to. The patrol gunner's `$0F` therefore means it can only be hurt while it is attacking. The four breakable walls (`$D0`–`$D3`) each break only to a charged shot of one particular sword. Crystalis has no element, so nothing blocks it.
- **Special cases:**
  - Type `$7B` turns into a hidden enemy (`$4F`) when hit by a fully charged shot.
  - With the thunder sword, some targets turn into a different object type. I couldn't tell which targets this is meant for.
- **Slot 3** is the talk / item-use box in front of the player. It starts NPC talks, pushes the player back off solid NPCs, and handles using an item on event objects.
- **Slot `$0C`** freezes whatever it hits and sets that object's flag. A variant of it destroys enemy shots instead.
- **Gold drop:** a killed enemy leaves a death puff, which spawns a coin (type `$0C`). Coin values by drop class are 0, 1, 2, 4, 8, 16, 30, 50, 100, 200, 400, then big coins worth 50, 100, 200, 400 and 500.
