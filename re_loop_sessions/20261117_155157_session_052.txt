**What I added**
- **`web/test/run.mjs`** runs the port in Node without a browser. It takes the same `--keys` scripts as `tools.emu` and writes the same per-frame CSV with `--compare`. It can also save a screenshot (`--dump-screen`, `--scale`) and dump RAM or WRAM. It runs at about 20,000 frames per second.
- **`--frame0` (default 214)** lines up frame numbers with the emulator. The port skips the 212-frame startup intro, and the emulator reaches the game's first main-loop pass at frame 214. With this default, key scripts and CSV frame numbers match `tools.emu` directly.
- **Button names need no bit reversal.** The emulator stores A in the lowest bit and the port stores it in the highest. Names like `A+RIGHT` map straight to the port's order, so only raw numeric emulator masks need converting (`rev8()` does it).
- **`web/test/harness.mjs`** is shared code: the key-script parser, the CSV row builder (column for column the same as `tools/emu/compare.py`), and a small PNG writer.
- **`tools/compare_frames.py`** diffs two CSVs by frame number. It can limit the check to column groups (`core`, `snd`, `pal`, `obj`) or a frame range, and can shift frames. It also diffs two PNGs using `render_compare.py`. It exits 1 on any difference.
